# 哲学依据与模型边界

查阅日期：2026-09-07。阅读 Stanford Encyclopedia of Philosophy 的 [Original Position](https://plato.stanford.edu/entries/original-position/) 正文（开篇、信息限制与争议相关段落），通过 Jina Reader 获取。它是学术百科解释，不冒充 Rawls 原著逐字引文。延伸入口：[John Rawls](https://plato.stanford.edu/entries/rawls/)，未在本轮逐段审阅。

来源指出，原初状态是为选择社会政治正义的基本原则而构造的公平视角。无知之幕排除个人特征和特定社会地位等信息；它仍允许某些一般知识。Rawls 的论证还涉及平等基本自由、公平机会以及差别原则，不能缩成“把固定预算分给六个人”。文中也介绍了该选择是否确定等争议。

Veil Lab 只借用“先选规则，再知道自己位置”的参与机制。六人的需求与线性收益数字全部可见；隐藏的只有使用者抽到哪一个位置。随机揭晓是本工具的玩法，并非对 Rawls 决策程序的忠实重现。

四条分配规则是本项目明确写出的数学模型：均分、满足需求后均分、最大化最低需求覆盖率、最大化总线性收益。后两条不分别等同于 Rawls 理论或功利主义的全部主张。资源是一种可分割抽象量，没有权利、自由、机会、历史、互惠、生产激励、动态制度或风险偏好等维度。

需求、收益与可加性由使用者设定；收益系数不表示人的道德价值。Gini 只比较本轮资源差距，同样的Gini可以对应不同水平的贫乏。最低覆盖率只表达资源/需求比值，也不是现实生活保障。页面的数值不构成实证证据，也不输出哪种规则道德上正确的答案。
